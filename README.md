# wangjin-market-data

WANGJIN 高雄房市行情自動更新資料。

## 更新與配對

- GitHub Actions 於臺灣時間每月 2、12、22 日 10:20 下載內政部當期資料，並補抓尚未成功匯入的歷史發布季度。
- 目前統計 2026 年符合住宅大樓、住家用等篩選條件的已揭露交易，不代表全年全部成交。
- 預售依官方案名與行政區唯一配對；`data/approved_project_aliases.json` 僅收錄有一手來源、名單身分與固定官方位置的已核對別名。新交易仍須通過官方編號、來源、位置與數值檢查。
- `data/community_mapping.csv` 僅確認特定完整門牌的社區名稱，不代表該社區所有門牌或建商首售。博市陞目前僅核對大學二十九路568號。
- `analysis/completed-home-review.json` 每次更新重建全部成屋建案的門牌缺漏、衝突、逐筆官方證據與屋齡候選。此清單不輸出價格、不建立建商首售對照。

## 2026-10-18 本次補齊

- 預售增加遠雄一靚、遠雄峰蘊、達麗世界學、善寬UNI的核對別名，56案／859筆提升為60案／969筆。來源與固定位置保存在別名表。
- 成屋244案：1案已有完整門牌社區核對、12案有待查證門牌成交、2案門牌共用衝突、57案在已收錄資料無同門牌成交、172案名單缺完整門牌。
- 博市陞568號對上2筆2026成交，列入社區統計；建商首售核實筆數仍為0。
- 成屋的剩餘工作主要是補完整門牌及一手證據；查無同門牌樣本不代表今年零成交。

## 驗證

`python -m unittest discover -s tests -v`

每次正式更新先跑官方證據與配對測試，再下載資料、重建公開預售資料與成屋待查清單。
