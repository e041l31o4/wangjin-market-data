# wangjin-market-data

WANGJIN 高雄房市行情自動更新資料。

## 更新與配對

- GitHub Actions 於臺灣時間每月 2、12、22 日 10:20 下載內政部當期資料，並補抓尚未成功匯入的歷史發布季度。
- 目前統計 2026 年符合住宅大樓、住家用等篩選條件的已揭露交易，不代表全年全部成交。
- 預售依官方案名與行政區唯一配對；`data/approved_project_aliases.json` 僅收錄有一手來源、名單身分與固定官方位置的已核對別名。新交易仍須通過官方編號、來源、位置與數值檢查。
- `data/community_mapping.csv` 僅確認特定完整門牌的社區名稱，不代表該社區所有門牌或建商首售。來源分為政府資料、建商官網與人工核對的建案／社區刊登頁，不將刊登頁標成官方證據。
- `analysis/completed-home-review.json` 每次更新重建全部成屋建案的門牌缺漏、衝突、逐筆官方證據與屋齡候選。此清單不輸出價格、不建立建商首售對照。
